# Docker Server Logger -> Telegram

Сервис на Python для ежедневного сбора логов всех запущенных Docker-контейнеров на сервере и их отправки в Telegram.

## Возможности
- Подключается к Docker-демону через `/var/run/docker.sock` (в режиме только для чтения `:ro`).
- Собирает логи всех запущенных контейнеров за последние `N` часов (по умолчанию 24 часа).
- Поддерживает 3 режима отправки (`SEND_MODE` в `.env`):
  - `files` *(по умолчанию)* — сводное сообщение + отдельный `.log` файл на каждый контейнер (с авто-сжатием в `.zip`, если размер превышает лимит Telegram).
  - `zip` — сводное сообщение + один общий `.zip` архив со всеми логами.
  - `text` — сводное сообщение + последние строки логов текстовыми сообщениями в чат.
- Работает по расписанию каждый день в заданное время (`SEND_TIME`) с учетом часового пояса (`TZ`).

## Быстрый старт

1. **Настройте `.env` файл**:
   Откройте файл `.env` и укажите токен вашего Telegram-бота и ID чата:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:AAH...
   TELEGRAM_CHAT_ID=123456789
   SERVER_NAME=My-Server
   TZ=Asia/Yekaterinburg
   SEND_TIME=09:00
   ```

2. **Запустите контейнер**:
   ```bash
   docker compose up -d --build
   ```

3. **Просмотр логов работы самого сервиса**:
   ```bash
   docker compose logs -f
   ```

4. **Остановка сервиса**:
   ```bash
   docker compose down
   ```
